A premium, highly-interactive academic portfolio for **Professor Ravindra Kumar Niranjan**, Assistant Professor of Chemical Engineering at BIET Jhansi. 

Designed with an "Awwwards-winning" aesthetic, this single-page application features a deep immersive dark theme, advanced physics-based micro-interactions, and 100+ smooth scroll-reveal animations.

🌐 **[View Live Demo Here](https://tejasblynk.github.io/rkniranjan.portfolio)**

---

## ✨ Key Features

- **🌌 Immersive Ambient Theme:** A pure pitch-black (`#000000`) canvas illuminated by dynamic, breathing purple, fuchsia, and violet radial gradients.
- **🚀 100+ Staggered Animations:** Every element utilizes cubic-bezier scroll-reveal animations for a buttery-smooth entrance as you scroll.
- **🧊 3D Tilt Glassmorphism:** Publication and Expertise cards feature interactive 3D tilting with simulated light glare based on mouse position.
- **🧲 Magnetic UI:** Navigation links and call-to-action buttons feature physics-based "magnetic" pulling effects when hovered.
- **🖱️ Custom Trailing Cursor:** A glowing violet cursor and spotlight that follows the user's mouse (intelligently disabled on mobile devices for UX).
- **✉️ Ultra-Prominent Contact Dock:** A fixed, glass-frosted bottom dock featuring an animated conic-gradient border and shimmering text to maximize communication opportunities.
- **📱 Fully Responsive:** Carefully optimized to look stunning on desktops, tablets, and mobile devices.

---

## 🛠️ Tech Stack

This project is built for maximum performance and zero build-step complexity, making it incredibly easy to host on GitHub Pages:

- **HTML5:** Semantic, accessible markup.
- **Tailwind CSS (via CDN):** Rapid, utility-first styling with custom configurations for fonts and animations.
- **Vanilla JavaScript (ES6):** Handles the Intersection Observers (scroll reveals), 3D tilt math, magnetic physics, and cursor tracking.
- **Phosphor Icons:** Clean, consistent line-art iconography.
- **Google Fonts:** Utilizing *Space Grotesk* for striking display headers and *Inter* for highly legible body text.
